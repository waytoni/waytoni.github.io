අනිච‍්චං --- අනිස ය (අනිසි-නිසි නැති): අනාගත යදනිච්ච සූත්‍රය සහ පච්චුප්පන්න යදනිච්ච සූත්‍රය

අංගුත්තර නිකාය → ඒකාදසක නිපාතතෝ → පඨම සඤ්ඤා සුත්තං

සංයුත්ත නිකාය → ඛන්ධක වග්ගෝ → හේතු සූත්‍රය

සංයුත්ත නිකාය → ඛන්ධක වග්ගෝ → ඛන්ධ සංයුත්තං → පළමු පණ්ණාසකය → භාර වර්ගය → පඨම අස්සාද සුත්තං

සංයුත්ත නිකාය → ඛන්ධක වග්ගෝ → ඛන්ධ සංයුත්තං → පළමු පණ්ණාසකය → භාර වර්ගය → දුතිය අස්සාද සුත්තං

සංයුත්ත නිකාය → ඛන්ධක වග්ගෝ → ඛන්ධ සංයුත්තං → පළමු පණ්ණාසකය → අනිච්ච වර්ගය (සූත්‍ර 10)

සංයුත්ත නිකාය → නිදාන වර්ගය → අභිසමය සංයුත්තං → මහා වර්ගය → සුසීම සුත්තං

සංයුත්ත නිකාය → නිදාන වර්‍ගය → අභිසමය සංයුත්තය → බුද්ධ වර්‍ගය → විභඞ්ග සූත්‍රය

සංයුත්ත නිකාය → නිදාන වර්‍ගය → අභිසමය සංයුත්තය → ආහාර වර්‍ගය → පච්චය (පච්චයුප්පන්න) සූත්‍රය

මජ්ඣිම නිකාය → මූල පණ්ණාසකකෝ → සබ්බාසව සුත්තං

සංයුත්ත නිකාය → සළායතන සංයුත්තය → සබ්බ වර්‍ගය → සබ්බ සූත්‍රය සහ ප්‍රහාණ සූත්‍රය

සංයුත්ත නිකාය → සළායතන සංයුත්තය → අනිච්ච වර්ගය - මතක තබා ගැනීමට උපකාරී වන කෙටි විග්‍රහය

සංයුත්ත නිකාය → සළායතන සංයුත්තය → අනිච්ච වර්ගය (සූත්‍ර 12)

ඛුද‍්දකනිකායො → මහානිර්දේශය → කලහවිවාදසූත්‍රනිර්දේශය (11.6)
